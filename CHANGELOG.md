# Changes

## 1.1.0

**English**

- The close button hides Kadr to the tray; exit from the tray icon menu. Starting Kadr again shows the window that is already running.
- Choose the audio tracks in the file: the mix and a track per source, the mix only (plays everywhere, the legacy Windows Media Player included), or the source tracks only.
- Move the recorded region while recording: drag the tab on its frame.
- All screens at once: in one video, laid out as in Windows display settings, or each screen into its own file.
- Kadr's window hides while you select a region, so it never covers what you select.
- The default audio track is encoded at a higher bitrate, so Windows players always play the mix.

**Русский**

- Крестик сворачивает Kadr в трей; выход — из меню значка в трее. Повторный запуск показывает уже открытое окно.
- Выбор звуковых дорожек в файле: микс и дорожка на каждый источник, только микс (играет везде, в том числе в старом Windows Media Player) или только дорожки источников.
- Записываемую область можно двигать во время записи — за ручку у рамки.
- Все экраны сразу: одним видео, как экраны стоят в параметрах Windows, или каждый экран своим файлом.
- Окно Kadr прячется на время выделения области и не закрывает то, что выделяете.
- Основная звуковая дорожка кодируется с большим битрейтом, поэтому плееры Windows всегда играют микс.
